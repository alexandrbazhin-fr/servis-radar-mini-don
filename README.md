# Сервис-радар мини-отеля «Мини-ДОН»

Интерактивный дашборд для управляющего мини-отелем в центре Ростова-на-Дону: события города, тарифы и акции конкурентов, акции общепита, отзывы и операционные метрики. Экспорт в CSV, .ics, PNG, Markdown, JSON и печать.

Данные загружаются из Google Таблицы [«Сервис-радар · Мини-ДОН — данные»](https://docs.google.com/spreadsheets/d/187vwGKd42T1nH9d23lL1wvXHiCN3-OMOEUjZVcV6cvo/edit) (онлайн, через Google Visualization API) или из снимка `sheet-data.js`.
